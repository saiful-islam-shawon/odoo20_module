# Source map

## Opportunity pages

- `views/fakir_reference_crm.xml`: Website CRM creation form.
- `views/crm_template.xml`: Other CRM portal form templates.
- `views/portal_crm_template.xml`: Opportunity listing, detail, products, and chatter markup.
- `views/website_menu.xml`: Website CRM navigation.

## Frontend behaviors

- `static/src/interactions/fakir_reference_crm.js`: Website CRM create form interactions.
- `static/src/js/fakir_v20_list_columns.js`: Opportunity list optional columns.
- `static/src/js/fakir_detail_products_inline.js`: Editable opportunity product rows.
- `static/src/js/fakir_details_live.js`: Chatter updates and message presentation.
- `static/src/js/fakir_smart_counts.js`: Meeting and quotation counter refresh.
- `static/src/js/fakir_assignment_toast.js`: Automatic assignment feedback.
- `static/src/js/fakir_activity_modal_click_fix.js`: Activity modal event isolation.
- `static/src/js/fakir_detail_readability.js`: Field display interactions.
- `static/src/js/fakir_extra_partner_search.js`: Extra Info and partner lookup behavior.

Other JS and SCSS files remain at their current paths for compatibility with registered assets and existing templates.
